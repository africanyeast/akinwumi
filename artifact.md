# Portfolio Strategy & Design Ethos: "The AI Product Manager"

## 1. The Core Shift
**From**: "Technical Product Manager" (Generic, coordinates engineering)
**To**: "AI Product Manager / Engineer" (Builder, bridges strategy & frontier models)

**The Insight**: The market (e.g., Manus, OpenAI) doesn't just want someone who can stick-handle a Jira board. They want someone who understands the *metal*—context windows, token economics, evals, and prompt engineering—and can translate that into user value.

## 2. The "Narrative-First" Design
We rejected the standard "Grid of Project Cards" because it generates friction. Senior roles require storytelling, not just cataloging.

**The Homepage as a Manifesto**:
Instead of burying the lead, the homepage *is* the proof of work.
-   **Hook**: "I bridge minds and actions." (Strategic alignment with agentic AI).
-   **Journey**: We walk the user through a specific problem (The Context Gap in simple search) and how we solved it.
-   **Embedded Evidence**:
    -   We display the **System Prompt** inline (using the `PromptViewer`). This proves you know how to talk to models.
    -   We display the **Code (Adapter Pattern)** inline. This proves you write robust software.

## 3. Key Concepts We Highlighted
To position you correctly, we focus on these specific pillars:

### A. "Context Engineering" vs. "Prompt Engineering"
Anyone can write a prompt. An AI PM understands *Context*. We explicitly show how we manage the user's intent vs. the database's metadata limitations.

### B. "0 to 1" Ownership
We frame projects not as "tasks I did" but as "products I birthed."
-   *Insight*: "Video editors waste 30% of their time."
-   *Solution*: An autonomous agent (Kopi).

### C. "Minds and Actions" (The Manus Criteria)
-   **Mind**: Strategic insight, user research, "why we built this."
-   **Action**: The tangible code, the specific tool calls, the evaluation metrics.

## 4. Design Guidelines (The "Plain/Premium" Aesthetic)
-   **Visuals**: High contrast, monochromatic with subtle semantic colors (blue/purple for AI).
-   **Typography**: Clean sans-serif (Inter/Geist) for reading; Monospace for technical credibility.
-   **No Fluff**: No "About Me" fluff. Every pixel is dedicated to demonstrating competence.

## 5. Future Project Template
When adding new work, follow the **Kopi** archetype:
1.  **The Pain**: What is the semantic gap or user friction?
2.  **The Agentic Insight**: Why is an Agent the right solution (vs. a filter or regex)?
3.  **The Artifact**: Extract the *one* prompt or piece of logic that is clever.
4.  **The Evals**: How do you know it works? (Mention Ragas, hallucinations rates, etc.)
